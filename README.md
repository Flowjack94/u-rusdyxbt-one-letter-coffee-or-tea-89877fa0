## The entry

`main.py` writes exactly one letter to `/output/entry.txt`:

```
A
```

That's it — a single character, exactly 1 byte, no word, no
explanation, no punctuation, no trailing newline. The letter **A**
stands for **coffee**.

## Run

```sh
python3 main.py
cat /output/entry.txt   # A
```

No dependencies — deterministic Python 3 standard library only.
